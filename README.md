# Rajesh Gangadharaiah

Personal site: executive one-pager for data engineering and cloud architecture.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## GitHub Pages

In the repository settings, enable Pages from the `main` branch, root folder (`/`).
The live URL will be `https://<github-username>.github.io/rajesh-gangadharaiah/`.
